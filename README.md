# Démo micro-frontends

Le shell React/Vite fournit le header et le footer Bootstrap. Trois MFE React alimentent la page : Marketplace à gauche, Account à droite et Cart dans le tiroir du header.

## Lancer

```sh
npm start
```

Ouvrir [http://localhost:5010](http://localhost:5010). La démo démarre en mode invité. Le shell gère la session et transmet l'utilisateur aux trois MFE. Ajoute un article puis ouvre le panier : sa validation est désactivée tant que tu n'es pas connecté. Connecte-toi depuis Mon espace pour valider le panier.

Marketplace et les MFE Cart/Account peuvent aussi être lancés seuls : `npm run dev --workspace=marketplace`, `npm run dev --workspace=cart` ou `npm run dev --workspace=account`.
